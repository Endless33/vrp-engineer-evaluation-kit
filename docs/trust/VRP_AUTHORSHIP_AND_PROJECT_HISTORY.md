# 3. Engineering Motivation

The project began with a simple engineering question:

> Should a temporary transport-path failure automatically terminate an otherwise valid logical communication session?

From this question, the project evolved into a broader investigation of:

- session continuity;
- transport independence;
- deterministic state management;
- authority consistency;
- replay resistance;
- recoverability;
- evidence generation;
- explicit trust boundaries.
